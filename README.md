## View Locally

Open `index.html` directly in a browser, or start a local server from the project directory:

```powershell
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000). On Windows, `py -m http.server 8000` can be used if `python` is unavailable.

## Deployment

The portfolio can be published as a static site with GitHub Pages or Firebase Hosting. For Firebase Hosting, generate the deployment-ready `dist/` directory and deploy with:

```powershell
node scripts/prepare-hosting.js
firebase deploy --only hosting --project YOUR_FIREBASE_PROJECT_ID
```
